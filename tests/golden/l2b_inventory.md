## Patterns

- Three code paths raise under Python 3 / NumPy 2 and were evaluated only through the script-local shims listed in the script docstring: MG94 IndCodonGeneconv (`len/3` in nts_to_codons), 'One rate' JSGeneconv (`dtype=np.floating` in IGCModel), and HMMJSGeneconv (implicit relative imports). Shimmed rows carry the shim name.
- ReCodonGeneconv summaries (`MG94_*`, `HKY_YLR406C_*`, `Force_MG94_*`) record `ll = 0.0`: get_individual_summary writes self.ll, which stays at its constructor value 0.0 unless a likelihood was evaluated first. Their parameter rows can still be checked against the save.
- HMMJSGeneconv.get_mle writes log tau into x[5], which is the tau slot only for MG94; the HKY and HKY+rv HMMJS saves and their internal IndCodonGeneconv saves therefore carry a corrupted first branch length (HKY) or r3 (HKY+rv).
- The YDR418W_YEL054C simulation fixtures (simulation_test_save, *_MG94_IGC_HMMJSGeneconv_save, HMMJS_YDR418W_*) cannot be evaluated: YDR418W_YEL054C_Simulation.fasta contains stop codons, which IndCodonGeneconv's MG94 codon map rejects.
- Where a recorded value and a save file both exist, the summary's own parameter rows tell whether they belong together (see 'Summary parameters vs model at x' in the notes). Every mismatch of a scalar lnL comes with parameter rows that also disagree with the save (max rel diff 0.036 to 25), i.e. the save and the summary were written at different x (saves overwritten by later runs, or summaries from another alignment); none points to a change in the likelihood code. The matches (all four JSGeneconv EDN_ECP fits, the YDR418W One-rate fit, the HMM HKY+rv fit, six of the eight EDN_ECP per-site files and two of the three PSJS per-pair files, plus the JS-format PSJS_HKY_EDN_ECP summary) agree to <= 1.4e-9 relative in lnL.
- The per-site files whose x is not stored at full precision (EDN_ECP_HKY_nonclock_sw_lnL_check: best candidate off by 3.9e-5 per site) or not stored at all (Force_EDN_ECP_MG94_nonclock_sw_lnL, YLR406C_YDL075W_sitewise_lnL, PSJS_HKY_YDR418W_YEL054C_nonclock_lnL_summary) do not match any save file in test/save.
