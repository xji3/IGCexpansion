\section{Summary}
\begin{itemize}
\item \textbf{No method is calibrated across tract lengths.} The Wald sandwich and global-$\lambda$ CLR intervals under-cover (0.74--0.92). Local-$\lambda$ CLR over-covers from $1/p = 50$ (0.99--1.00). The bootstrap percentile interval misses on one side.
\item \textbf{Short tracts ($1/p \le 100$):} Wald intervals have the best median interval scores (even the naive one at $1/p \le 10$; the sandwich at 50--100). Local-$\lambda$ CLR is far too wide at $1/p \le 10$.
\item \textbf{Long tracts ($1/p \ge 200$):} local-$\lambda$ CLR has the best interval score, on both mean and median (on the mean already from $1/p = 50$). It is conservative but still narrower than the sandwich and global-$\lambda$ intervals, which are both wider and miss more.
\item \textbf{The estimate $\widehat{1/p}$ is biased low} for $1/p \ge 10$. At a true $1/p$ of 500 the median estimate is 123.
\item \textbf{The bootstrap percentile interval inherits that bias.} It covered 10 of 16 test cases, and every miss had the truth above the interval.
\item \textbf{Real data:} all 17 datasets now have refits and bootstrap intervals. The Harpak\_introns ``optimizer failures'' were a false alarm (Section~6).
\end{itemize}

\section{What was run}
\textbf{Simulation (arm L).} The 2017 archive datasets: 8 cells with true $1/p$ of 3, 10, 50, 100, 200, 300, 400 and 500, $\tau$ fixed, 100 datasets per cell. Replicate 88 of the 400 and 500 cells is the same alignment (identical SHA-256). Re-running the 2017 simulator (commit 12a0691, converted to Python 3), which reproduces archived replicates byte for byte, gives that alignment in both cells: the cells share seeds by design (27606 + replicate), and here the gene-conversion tracts covered the same differing sites. It is a genuine draw in each cell and is included, so all 800 datasets are used. Every dataset was fitted with the current M2 procedure (L-BFGS-B, several starts in $\psi$, Newton-decrement convergence).

\textbf{Intervals} are for $\psi = \log(1/p)$ and shown as $1/p$:
\begin{itemize}
\item \textbf{Wald, naive:} $\hat\psi \pm 1.96\,\mathrm{SE}$ from the inverse Hessian, ignoring the composite likelihood.
\item \textbf{Wald, sandwich:} the same with the Godambe variance $H^{-1} J_{PB} H^{-1}$.
\item \textbf{CLR, global $\lambda$:} $\{\psi: W(\psi) \le 3.84\,\lambda\}$ with $\lambda$ evaluated once at $\hat\theta$.
\item \textbf{CLR, local $\lambda$:} the same with $\lambda(\psi)$ re-evaluated at each profile point, using the expected Hessian $H_E$.
\item \textbf{Bootstrap percentile:} the 2.5\% and 97.5\% quantiles of $\hat\psi^*$ over $R = 100$ datasets simulated at $\hat\theta$, each refitted over all parameters with the full M2 procedure. This was run only for replicates 1--2 of each cell (16 datasets), because each costs 35--70 GPU-minutes.
\end{itemize}

\textbf{Interval score} (Gneiting and Raftery, 2007), on the $\psi$ scale, at $\alpha = 0.05$:
\[ S(\ell, u; \psi_0) = (u - \ell) + \tfrac{2}{\alpha}(\ell - \psi_0)_+ + \tfrac{2}{\alpha}(\psi_0 - u)_+ . \]
Lower is better. It rewards narrow intervals but charges 40 times the distance by which an interval misses the truth, so neither a very wide interval nor a narrow one that misses scores well. An unbounded upper end is scored at $\psi = \log 10^4$.

\begin{itemize}
\item \textbf{Wald, naive} ignores the dependence between site pairs. It is far too narrow in most datasets (coverage 0.06--0.16 from $1/p = 50$) and occasionally enormous (mean widths of 131--204 at $1/p = 300$--400). At $1/p \le 10$ its narrowness happens to pay off on the median score.
\item \textbf{Wald, sandwich} is symmetric in $\psi$, but the profile is lopsided: flat above $\hat\psi$, steep below. The interval is too short above and too long below (lower ends under $1/p = 1$ at long tracts). Its miss penalty grows with $1/p$.
\item \textbf{CLR, local $\lambda$} has the right lopsided shape and almost never misses from $1/p = 50$ on. It is too wide, especially at $1/p \le 10$, where its upper end reaches several hundred. A likely cause is that $\lambda(\psi)$ grows quickly with $\psi$ (from 8 to 352 on EDN\_ECP), raising the cutoff exactly where the upper end is decided.
\end{itemize}

\textbf{Harpak\_introns.} Its M2 fit and all 100 bootstrap refits were labelled \emph{optimizer failure}, so the percentile step first excluded every refit.
\begin{itemize}
\item \textbf{Cause:} Harpak is the only non-coding dataset, so the codon-position rates $r_2$, $r_3$ do not enter the likelihood. The IS fit and the uncertainty step hold them fixed, but the M2 fit left them free. Their exactly zero gradient and curvature spoil L-BFGS-B's inverse-Hessian approximation, and with it the Newton decrement the optimizer reports (0.059 for the M2 fit, threshold $10^{-2}$).
\item \textbf{Check:} the Newton decrement from a finite-difference Hessian of the exact gradient, on the 16 parameters the likelihood depends on, is $5.6\times10^{-5}$ for the M2 fit and at most $3.7\times10^{-4}$ for every bootstrap refit. All are converged; the four M2 starts agree to $10^{-9}$ in $cl$.
\item \textbf{Result:} bootstrap interval $[39, 941]$ with median 195, from all 100 refits.
\item \textbf{Code fix:} \texttt{fit\_m2} now holds $r_2$, $r_3$ fixed for non-coding data (\texttt{IGCexpansion.psigc}), so a rerun with this code no longer shows the false alarm.
\end{itemize}

Where both are finite, the bootstrap upper end is 3 to 530 times lower than local CLR's (median 20 times). Given Section~5, the bootstrap is the less trustworthy of the two on that side.

\section{Open questions}
\begin{itemize}
\item \textbf{Calibrating local-$\lambda$ CLR.} Over-coverage means the cutoff $3.84\,\lambda(\psi)$ is too large. The empirical 95th percentile of $W(\psi_0)/\lambda(\psi_0)$ at the true $\psi_0$, per cell, would show by how much, and whether one correction works across tract lengths. It can be computed from the saved profiles without a GPU, but $\lambda$ was saved at only about 7 points per dataset, so the estimate would be approximate.
\item \textbf{Downward bias of $\hat\psi$.} Its source (composite likelihood, limited information in one alignment, or the optimizer) is not yet known, and it limits any interval centred on $\hat\psi$.
\item \textbf{A hybrid rule} (sandwich for short estimated tracts, local CLR for long) would need its own simulation check, because choosing by $\hat\psi$ changes coverage.
\item \textbf{Sandwich with $H_E$} instead of the observed Hessian changes only the variance; the symmetric shape, and so the long-tract misses, would remain.
\end{itemize}
